# Security Reports (Bandit)

This directory contains static analysis results generated by Bandit.

Generated files:
- bandit-report.json — Full Bandit findings in JSON format (machine readable).
- bandit-summary.txt — Human-readable summary of findings.

Generation commands run from BackendAPIService/:
- python -m pip install --upgrade pip
- pip install bandit
- mkdir -p security-reports
- bandit -r . -f json -o security-reports/bandit-report.json
- bandit -r . -f txt -o security-reports/bandit-summary.txt

Note on SARIF:
- The installed Bandit version does not currently support SARIF output. If SARIF is required for CI, consider converting the JSON using a separate tool or use a Bandit build that includes SARIF support when available.
