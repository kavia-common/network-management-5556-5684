## Testing

The backend uses pytest with reporting configured by default.

How to run:
- From BackendAPIService directory:
  - pip install -r requirements.txt
  - pytest

Reports generated by default:
- JUnit XML: reports/junit/backend.xml
- HTML report: reports/html/backend/index.html

For coverage (recommended):
- Install pytest-cov and run:
  - pytest --cov=app --cov-report=term-missing --cov-report=xml:reports/coverage.xml --cov-report=html:reports/html/coverage

See backend_unit_test_report.md for detailed testing strategy, example tests, mocking guidelines (MongoDB and network), and CI recommendations.
